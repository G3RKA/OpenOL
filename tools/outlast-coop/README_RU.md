# Outlast вдвоём на OpenOL 2.1.0: инструкция для хоста и друга

Проверено только на одном ПК с двумя копиями игры. **Через интернет между двумя ПК не проверялось.** Файлы игры и релиза OpenOL здесь не лежат: только патчи, скрипты и тесты.

## Что нужно обоим
- Outlast из Steam (проверено на билде 576074) с DLC Whistleblower.
- Релиз OpenOL 2.1.0 (`OpenOL.zip` из репозитория автора). Ставить его нужно поверх **копии** папки игры, а не оригинала: папку Steam и облачные сохранения не трогаем. Перед установкой сохраните файлы, которые заменяются.
- Windows PowerShell 5.1 или новее.

## Один раз: патч против двойных врагов (у обоих игроков)
Без патча у каждого игрока своя копия врага карты, и в одном месте стоят два врага. С патчем остаётся один: настоящий у игрока, который зашёл первым, у второго он показан как копия.
1. Нужен чистый `OLGame.exe` из релиза OpenOL 2.1.0 (SHA-256 `2e58afbb1203d04476581f34216428d1dfc96228e5f3df8c6881323c56c93346`).
2. В PowerShell: `.\play\apply-native-patch.ps1 -Exe "<копия игры>\Binaries\Win64\OLGame.exe" -Out "<папка>\OLGame_patched.exe"`. Скрипт не меняет исходный файл и отказывается работать с другой версией.
3. В копии игры замените `OLGame.exe` на `OLGame_patched.exe`, исходный сохраните рядом.
4. После патча переключатель `SyncEnemies=False` не нужен.

## Хост (кто принимает подключения)
1. Нужен relay (сервер). Три варианта:
   - Автономный `OpenOL_Relay.exe` из релиза OpenOL-Relay: комната `PUBLIC`. В нём не отправляется «снимок мира» подключившемуся позже. Исправлено патчем `relay-patches/0003`.
   - Собрать relay с нашими патчами: см. `relay-patches/README.md` (даёт `--trigger-radius`, правильные коды врагов, снимок для вошедшего позже).
   - Relay внутри игры (F6, вкладка Relay, Start Relay): комната `DEFAULT`. Не отправляет позицию врага вошедшему позже.
2. Запуск: `.\play\host.ps1 -Relay <путь к OpenOL_Relay.exe>` (по умолчанию порт UDP 7777, можно `-TriggerRadius 3000` с патченым relay). Скрипт покажет адреса вашего ПК: скажите другу тот, что из сети, общей с ним (интернет с пробросом порта UDP 7777 на роутере, либо VPN-сеть вроде Radmin или ZeroTier).
3. Если Windows Firewall покажет окно при запуске relay, нажмите «Разрешить доступ» сами (частные сети; для VPN тоже). Скрипты ничего в брандмауэре не меняют.
4. Хост тоже подключается как игрок к своему relay (адрес 127.0.0.1).

## Каждый игрок: подключение
1. `.\play\join.ps1 -GameDir "<копия игры>" -HostIp <адрес хоста> -Name <имя>` записывает `OLGame\Config\OLMultiplayer.ini` (сохраняя копию старого файла). Комната `PUBLIC` по умолчанию; для relay из игры `-Room DEFAULT`.
2. Запустите игру из копии (`Binaries\Win64\OLGame.exe`; для отдельного профиля добавьте `-nosteam`).
3. Главное меню: Multiplayer, поля уже заполнены, затем Connect. В углу появится `<имя>: 2 players` и пинг.
4. У каждого: New Game, Main, сложность, Continue. Оба стартуют в машине, катсцена идёт одновременно, затем чекпоинт `Admin_Gates` сохраняется сам. Партнёра видно в мире.
5. После вступительного письма нажмите Enter.

## Как играть
- Держитесь рядом: сюжетные триггеры сейчас срабатывают у обоих игроков независимо от того, где стоит второй (патч relay с радиусом смягчает это).
- Загрузка чекпоинта у одного игрока второго не переносит: загружайте один и тот же чекпоинт сами.
- Двери, смерть и возрождение, враги синхронизируются.

## Известные проблемы
- Два разных врага одного класса ближе 150 единиц друг к другу патч может принять за дубль и удалить одного.
- Прыжки между чекпоинтами разных групп через оверлей F6 иногда роняют игру ошибкой движка (`Sequence != RootSequence`), это бывает и с одним игроком.
- Предметы, толкаемые объекты и катсцены проверены только на уровне протокола, в реальном прохождении не проверены.
- Если relay недоступен, игра показывает «Connecting» без ошибки; неверный код комнаты ошибки тоже не показывает (`PUBLIC` для автономного relay, `DEFAULT` для встроенного).

## Если не подключается
Проверьте: адрес и порт, что UDP открыт, одинаковый код комнаты у всех, что relay запущен до подключения, что у всех установлен OpenOL 2.1.0 и DLC.

См. `harness/README.md` и результаты в `README.md`: 67 PASS и 4 известных XFAIL на патченой игре.
